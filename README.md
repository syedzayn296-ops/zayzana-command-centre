# Zayzana Command Centre

Zayzana Tech's lightweight operating dashboard for projects, leads, follow-ups and execution priorities.

## Current build

**V2 — browser-local working tracker**

The Command Centre currently provides:

- project progress tracking
- daily task completion
- lead and pipeline capture
- follow-up dates
- client and revenue metrics
- owned-asset and idea tracking

Data is stored in the browser with `localStorage`. No paid database or external service is required for the current prototype.
